# Установка

## Требования

- MikoPBX **2025.1.1+** (используется REST API v3 с автодискавери)
- PHP 8.4 (входит в MikoPBX)
- Сервер Prometheus 2.x+ — отдельная машина
- Свободный TCP-порт (по умолчанию `9713`)

## Способ 1 — из архива (рекомендуется)

1. Возьмите `ModulePrometheus.zip` из релизов проекта
   (или из корня репозитория).
2. В веб-интерфейсе MikoPBX откройте **Модули → Установленные**.
3. Нажмите **Загрузить модуль** и выберите zip-файл.
4. Дождитесь завершения установки — модуль появится в списке.
5. **Включите модуль** переключателем.

> [!info] Что происходит при включении
> - создаётся таблица настроек `m_ModulePrometheus`;
> - регистрируется firewall-правило на порт экспортера;
> - добавляются две cron-задачи: health-check (раз в минуту) и
>   обновление кэша CDR-статистики (раз в 5 минут);
> - запускается воркер-экспортер.

> [!info] Обновление с 1.3.x
> Новые колонки настроек (`allowed_source_ip`, `publish_channel_quality`,
> `max_concurrent_scrapes`) добавляются установщиком автоматически по
> аннотациям модели. Уже сохранённые настройки не теряются.

## Способ 2 — из исходников

> [!danger] Структура архива
> `module.json` обязан лежать **в корне zip**. Если он окажется внутри
> `ModulePrometheus/`, установка падает с ошибкой
> «В архиве модуля … не найден файл module.json». MikoPBX читает манифест
> через `$zip->getFromName('module.json')` — строгое имя записи.

```powershell
# Windows (PowerShell) — собирает и сразу проверяет структуру
powershell -ExecutionPolicy Bypass -File .\build-module.ps1
```

```bash
# Linux / macOS. Точка после содержимого — ключевой момент:
# "zip -r zip ModulePrometheus" положил бы всё в подпапку.
cd ModulePrometheus
zip -r ../ModulePrometheus.zip .
cd ..
```

Скрипт `build-module.ps1` после сборки открывает архив и проверяет, что
`module.json` лежит в корне, а имена записей не содержат `..`, `\`
и ведущий `/`.

> [!warning] Переводы строк и права
> Скрипты `bin/*.sh` обязаны иметь LF-переводы строк. Права на запуск
> (`chmod 755`) модуль выставляет сам при старте службы, поэтому zip,
> собранный даже на Windows, работоспособен.

## Проверка после установки

1. Откройте страницу модуля — статус должен стать **Запущен**,
   отобразятся PID, версия и URL метрик.
2. Проверьте endpoint с самой АТС (или из разрешённой подсети):

```bash
curl -s http://127.0.0.1:9713/-/healthy
# ok

curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:9713/-/ready
# 200 - все сборщики отработали, 503 - есть падающий

curl -s http://127.0.0.1:9713/-/info | head -20
# JSON со счётчиками экспортёра: запросы, ошибки, последний сбор

curl -s http://127.0.0.1:9713/metrics | head -20
# # HELP mikopbx_exporter_build_info ...
# # TYPE mikopbx_exporter_build_info gauge
# mikopbx_exporter_build_info{module="ModulePrometheus",version="1.4.2"} 1
```

Если что-то не работает — см. [[Траблшутинг]].

## Удаление

Отключите модуль (воркер и cron-задачи будут сняты), затем удалите его
через интерфейс. Настройки и кэш удаляются вместе с модулем: `PbxExtensionSetup::unInstallFiles()`
гасит воркер и сносит `/storage/usbdisk1/mikopbx/tmp/ModulePrometheus`.
