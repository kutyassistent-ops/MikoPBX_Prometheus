# 🧭 ModulePrometheus — карта документации

> [!abstract] Что это
> **ModulePrometheus** — модуль MikoPBX, который отдаёт метрики в формате
> Prometheus (text exposition 0.0.4) по HTTP. Prometheus-сервер сам
> скрейпит эндпоинт — push-агент (как в Zabbix) не нужен.

## Быстрые факты

| Параметр | Значение |
|---|---|
| Endpoint | `http://<АТС>:9713/metrics` |
| Порт по умолчанию | `9713` |
| Формат ответа | Prometheus text 0.0.4 |
| Требования | MikoPBX 2025.1.1+, PHP 8.4, Prometheus 2.x+ |
| Авторизация | выключена, включается чекбоксом; токен в браузер не попадает |
| Ограничение доступа | список разрешённых IP/CIDR проверяется на каждом подключении |
| Версия модуля | 1.4.2 |
| Доп. эндпоинты | `/-/ready`, `/-/info`, `HEAD`, gzip |
| Готовые правила | `examples/alerts.yml` |
